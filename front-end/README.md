# Front-end Los Pit

Aplicação React mobile first. A sessão usa access token somente em memória; o refresh token permanece em cookie `HttpOnly` emitido pela API.

Configure `.env` a partir de `.env.example` e execute `npm run dev -w front-end`.

Antes de publicar, substitua o domínio de `public/robots.txt` e `public/sitemap.xml`, além dos dados oficiais indicados no `.env.example`.
